연습모드·리플레이에서 지금 살 아이템과 찍을 스킬을 강조 테두리로 알려 주는 인게임 팝업 오버레이와 전적 DB 자동 기록까지. 별도 설정 없이 클릭 한 번으로 내 PC에서 바로 실행하세요.

최신 버전 v1.4 모델 버전 - 지원 OS Windows · macOS

Windows

모든 인게임 오버레이(항상 위 고정), 구매·스킬 강조 테두리, 자동 전적 저장을 사용할 수 있습니다.

Windows 다운로드 파일 .bat 원클릭 실행기

macOS

Swift 네이티브 항상 위 플로팅 패널과 로컬 브리지 연동 오버레이를 사용할 수 있습니다.

macOS 다운로드 파일 .command 실행기
STEP 1

OS에 맞는 런처 받기

위 버튼을 누르면 현재 서버 주소가 자동 입력된 경량 실행기 파일이 내려받아집니다.

STEP 2

더블클릭으로 자동 실행

Python 3만 있으면 추가 설치 없이 최신 브리지 스크립트를 서버에서 받아 팝업을 띄웁니다.

STEP 3

연습모드 · 리플레이에서 확인

롤 화면 설정을 '테두리 없음'으로 두면 우측 상단 항상 위 HUD와 강조 테두리가 동작합니다.

관전·리플레이·연습 모드 전용 (공개 점수판 API 127.0.0.1:2999 만 사용 · 랭크 미사용) Python 3 표준 라이브러리 기반 · 추가 pip 설치 불필요
