LoL 페이스메이커 데스크톱 다운로드

연습모드·리플레이에서 지금 살 아이템과 찍을 스킬을 강조 테두리로 알려 주는 인게임 팝업 오버레이와 전적 DB 자동 기록까지. 별도 설정 없이 클릭 한 번으로 내 PC에서 바로 실행하세요.

최신 버전 v1.20 모델 버전 - 지원 OS Windows · macOS

Windows

프레임 없는 반투명 인게임 팝업 HUD(F8 클릭통과·F9 숨김), 전 라인·골드·아이템 기반 실시간 맞춤 전략, 자동 전적 저장을 사용할 수 있습니다.

Windows 다운로드 파일 .bat 원클릭 실행기

macOS

Swift 네이티브 항상 위 플로팅 패널과 로컬 브리지 연동 오버레이를 사용할 수 있습니다.

macOS 다운로드 파일 .app 번들 (.zip) 처음 열 때 '확인되지 않은 개발자' 창이 뜨면 앱을 Control+클릭 → 열기(macOS 15 이상은 시스템 설정 → 개인정보 보호 및 보안 → '그래도 열기'). 첫 실행은 팝업 준비에 30초쯤 걸리고, 팝업을 닫으면 프로그램도 끝납니다.
STEP 1

실행기 받기

버튼을 누르면 이 서버 주소가 들어간 실행기를 받습니다. 브라우저가 '위험할 수 있음' 경고를 띄우면 '유지', Windows가 'PC 보호' 창을 띄우면 '추가 정보 → 실행'을 누르세요.

STEP 2

더블클릭 한 번 (터미널 창 없음)

Python 3.9 이상이 없으면 자동 설치를 시도합니다. 실행 직후 검은 창은 자동으로 닫히고 백그라운드에서 동작합니다. 끌 때는 HUD 우측 상단 × 버튼을 누르세요.

STEP 3

롤 화면 모드 확인 및 실행

Windows 10/11 전체 화면 최적화(FSO) 환경에서는 전체 화면에서도 팝업 표시를 시도하며, 가려지면 설정 → 동영상 → 창 모드를 '테두리 없음'으로 바꾸세요. 게임이 시작되면 HUD가 'LIVE'로 바뀌고 F8(클릭통과)·F9(숨김)로 조작할 수 있습니다.

관전·리플레이·연습 모드 전용 (공개 점수판 API 127.0.0.1:2999 만 사용 · 랭크 미사용) Python 3 표준 라이브러리 기반 · 추가 pip 설치 불필요
