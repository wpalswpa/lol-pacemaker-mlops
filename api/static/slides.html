③ 왜 이 구조인가

설계 이유 다섯 가지

1

규칙과 경쟁하는 게이트

"골드 1,000당 약 +10%p" 규칙보다 확률이 정확할 때만 배포

Brier 0.1891 < 0.1917
2

정규화 내장 ONNX

학습·서빙 계산 차이를 없애고 서버에 학습 라이브러리를 안 깐다

오차 1.19e-07이미지 430MB
3

코드 판 · 모델 판 분리

v1.0 과 mYYYYMMDD-N. 패치 날엔 이미지 없이 모델만 교체

baked → m…-1 → m…-2
4

키 없는 배포

서버 안 러너, EC2 는 OIDC, 파일은 잡 출력으로. 저장소에 키 0개

SSH·AWS 키 0
5

즉시 되돌리기

옛 판을 버킷에 남겨 재학습 없이 되돌리고, 안 뜨면 스스로 복구

롤백 실측 16초
